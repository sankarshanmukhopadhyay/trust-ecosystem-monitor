Evidence and inference methodology

Observation: a source-linked issue/PR lifecycle event with repository, timestamp, event type and canonical GitHub URL.

Bounded inference: a same-month opened-and-merged PR pair supports the statement that a PR moved from opening to merge. It does not establish quality, adoption, approval, implementation, interoperability or governance consequence.

Not established: Confluence page modification cannot be classified as an adopted decision; a calendar listing cannot establish a meeting was held. Missing sources must not be treated as zero activity.

Publication is independent of ToIP. No automated LLM-generated or unreviewed semantic claims are made. Source-specific scope, authorization and privacy gates must be satisfied before external records are integrated.
